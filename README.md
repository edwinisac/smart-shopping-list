# 🛒 Smart Shopping List

A simple and responsive web application that helps you manage your shopping list.  
Built with **HTML**, **CSS**, and **JavaScript**.

---

## 🚀 Features
- ➕ Add products  
- ✏️ Update products  
- ❌ Remove products  
- 💾 Persistent storage using **Local Storage**  
- 📱 Responsive design for mobile and desktop
